# AlgoViz 工程蓝图风全新前端设计 Demo

日期：2026-07-31
状态：已与用户确认设计方向（brainstorming 两轮问答 + 两节设计呈现）

## 目标

在功能不变的前提下（算法目录、代码编辑、AI 生成动画、播放控制、终端、设置），完全抛弃现有前端视觉，产出一份有设计感、交互性强、去 AI 模板化、组件大胆的全站四页 HTML 设计 demo，放在 `design-demos/`。

## 范围

- 单文件 `design-demos/algoviz-blueprint.html`，内嵌四视图（首页/工作区/AI 实验室/设置），顶部导航切换，hash 路由（`#home` `#workshop` `#lab` `#settings`，缺省 `#home`）。
- 纯 HTML/CSS/JS 手写，无框架、无构建、无外部字体 CDN（等宽用 `JetBrains Mono` 本地优先、降级 `ui-monospace`）。
- 内容取材真实算法目录（冒泡、快排、二叉树、BFS、Dijkstra、堆等），复杂度标注真实；动画为手写示意场景，非生产 Scene Engine。
- 中文 UI。

## 视觉语言（工程蓝图）

- 纸面 `#F7F8FA`，蓝图蓝主线 `#2F6BFF`，深描边墨蓝 `#12307A`，标注红 `#E0453A`，验收绿 `#1E9E6A`，琥珀 `#D98324`，淡蓝填充 `#E3EBFF`。
- 网格纸底纹：细点阵 + 每 5 格强调线（CSS repeating-gradient）。
- 全站等宽字体（仪器感，去模板化的核心）。
- 签名组件：
  1. 图纸框 + 标题栏（`DRAWING No.XX` / `SCALE 1:1` / `SHEET x/4` / 右下角图章）
  2. 尺寸标注线（`|←── n=5 ──→|`，SVG 1px 细线 + 箭头）
  3. 红色定位十字游标（当前步标记）
  4. 标注线 Callout（图元引出折线 + 文字标签）
  5. 点线虚线表非活跃连接，实线表当前
  6. 图章：AI 生成完成「AI 生成」章 / 播放完成「验收通过」绿章 / 失败「退回返工」红章
- 动效模拟"绘图"：元素出现=描边动画（stroke-dashoffset）、游标短促位移、AI 生成=蓝色扫描线 + 打字机效果、页面切换=图纸翻转。统一 cubic-bezier 缓动，不用弹跳。
- 终端反色：深蓝底绿字，作为"设备"与纸面对比。

## 四页结构

### ① 首页 · 总图目录
- 巨型等宽标题 `ALGOVIZ · 算法图纸库` + 副标注；右上导航四页链接。
- 图纸网格：每个算法类别一张"缩略图纸"卡片（编号 `SHT-01`、类名、数量、微缩结构图）。
- 交互：悬停浮起 + 微缩图播放；点击进入工作区并选中分类；顶部图纸检索框。
- 底部签核行（MIT / V1.0 / 中英）。

### ② 工作区 · 工艺图纸（核心）
- 四栏分区（细蓝边框）：左 CODE SHEET（textarea 等宽 + 行号列 + 当前行红色定位十字 + 标注线）、中 SCENE（SVG 画布网格纸底：数组零件块、尺寸标注比较线、圆弧交叉交换、树/图节点+引脚、Callout 步骤说明）、右 SPEC 标注（步骤列表 + 统计刻度 + 变量面板）、底播放轨道（蓝色轨道线 + 红色十字游标 + 机械方钮 + 速度刻度 + 反色终端）。
- AI 生成按钮 `⌀ 生成图纸` → 扫描线动画 → 盖「AI 生成」章；提交按钮 = 「提交」图章。
- 手写动画场景：冒泡排序（可播放/单步/调速）、快速排序、二叉树插入、图 BFS（4 选 2~3 个实现完整，其余以静态图纸呈现）。

### ③ AI 实验室 · 实验记录
- 代码输入区（语言签注 PY/JS/CPP/JVM 标签切换）+ 输入数据字段。
- 历史记录带：实验记录簿横向条目（EXP-042、语言、时间、状态章）。
- 结果区复用 SCENE 画布；失败盖「退回返工」红章。

### ④ 设置 · 铭牌参数表
- 铭牌式表单（BASE URL / MODEL / API KEY 等宽大标签 + 下划线输入框）。
- 「测试连接」→ 成功盖「链路正常」绿章。
- 语言切换方钮（中/EN）、存储提示 + 存档图章。

## 非目标

- 不接入真实 AI、真实 Scene Engine、真实 i18n；全部示意性模拟。
- 不做生产迁移方案（demo 仅为设计评审参考；若选定，迁移方案另议）。
- 不重排现有 src/ 代码。

## 成功标准

- 打开文件即可预览四页，导航、hash 路由、播放控制、生成动画、图章交互均可用。
- 视觉上明显区别于现有 Observable/D3 风格与 signal-room 控制台风格。
- 无外部依赖、无构建步骤。

## 验收方式

用户人工验收（打开 HTML 预览）；本 demo 无 tsc/测试适用场景。
