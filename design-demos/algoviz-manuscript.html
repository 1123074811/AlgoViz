代码 · CODE
01function bfs(graph, start) {
02 const seen = new Set([start])
03 const queue = [start]
04 while (queue.length > 0) {
05 const node = queue.shift()
06 for (const next of graph[node])
07 if (!seen.has(next)) seen.add(next), queue.push(next)
08 }
09}

卷五
CRAFTSMANSHIP

匠心，藏在看不见的地方。

好的可视化不是「画出来」而已 —— 它要精确、稳定、经得起单步推敲。

其一 · TWEEN LAYER

交换，以直线交叉表达

补间层识别「值互换」语义，让两个元素沿直线交叉滑过 —— 路径与坐标系无关，数组单元与树节点共用同一机制。终态在数学上精确等于目标场景，支持 prefers-reduced-motion 降级。

其二 · GEOMETRY CONTRACT

几何契约：边不压字，字不压点

共享几何管线统一测量每个可见图元与文本，确定性生成避障边路由与标签避碰位置。每一步都通过 validateSceneGeometry 门禁：拒绝重叠、穿线与箭头遮挡。

其三 · ROBUSTNESS & TRUST

分层健壮，本地优先
